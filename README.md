# CRUD sencillo de personas

1. Ejecuta `database.sql` en MySQL.
2. Cambia usuario, contraseña o base de datos en `conexion.php` si hace falta.
3. En esta carpeta, ejecuta `php -S localhost:8000`.
4. Abre `http://localhost:8000`.

Archivos: `index.php` lista personas, `crear.php` las agrega, `editar.php` las modifica y `eliminar.php` las elimina. La conexión usa MySQLi.
